# Yank's Blog

## 📁 目录结构（更新不一定同步）

```text 
.
├── index.html              # 首页
├── posts.html              # 文章列表页
├── about.html              # 关于页
├── project.html            # 项目展示页
├── links.html              # 友人帐/友链页
├── posts/                  # 文章文件夹
├── css/
│   └── style.css           # 全站样式
├── js/
│   ├── B_word.js           # 碎碎念
│   ├── animations.js       # 滚动入场动画
│   ├── player.js           # 背景音乐播放器
│   └── nav.js              # 无刷新页面导航
├── assets/
│   └── profile.jpg         # 头像
├── .gitignore
└── README.md
```

### 👀 访问统计

页脚使用 [不蒜子](https://busuanzi.ibruce.info/) 统计全站浏览数与访客数，无需注册后端，引入脚本即可。
